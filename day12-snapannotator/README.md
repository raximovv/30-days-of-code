# Day 12: SnapAnnotator

Takes a frame from your webcam and asks a local vision model to describe what it sees. It uses Ollama with the moondream model.

## Run
```
python day12.py
```

## Install
```
pip install pillow opencv-python
```
Also install Ollama (https://ollama.com):
```
ollama pull moondream
```

## Controls
Press Q to quit.
