# Day 15: AudioScope

A live spectrum analyzer for your microphone. It runs an FFT on the incoming sound and plots the frequencies in real time.

## Run
```
python day15.py
```

## Install
```
pip install matplotlib numpy pyaudio
```

## Controls
Close the plot window to quit.

## Notes
For pyaudio on Windows: `pip install pipwin`, then `pipwin install pyaudio`.
