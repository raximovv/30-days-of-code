# Day 04: BlinkLock

Lock your screen by blinking. The webcam watches your eyes with MediaPipe and counts your blinks. After enough blinks in a row, it locks.

## Run
```
python day04.py
```

## Install
```
pip install opencv-python mediapipe
```

## Controls
Blink the required number of times to lock. Press U to unlock. Press Q to quit.
