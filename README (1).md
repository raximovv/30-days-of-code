# Day 01: RockLook

Music plays when you look down and pauses when you look up. It tracks your face through the webcam with MediaPipe and reads your head tilt.

## Run
```
python day01.py
```

## Install
```
pip install opencv-python mediapipe pygame
```

## Controls
Look down to play, look up to pause. Press Q to quit.

## Notes
Put an audio file named `music.mp3` in this folder before running. Any short track works.
