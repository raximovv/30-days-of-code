# Day 07: KeyboardOscilloscope

Turns your keyboard into a simple synthesizer. Each key plays a sine wave, and the live oscilloscope shows how the waves add together when you press more than one.

## Run
```
python day07.py
```

## Install
```
pip install numpy pygame sounddevice
```

## Controls
Press keys to play notes. A window opens with the waveform. Close it to quit.
