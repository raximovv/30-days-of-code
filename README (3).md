# Day 02: AirCanvas

Draw in the air with your index finger. The webcam tracks your hand with MediaPipe, and your fingertip leaves a line on the screen.

## Run
```
python day02.py
```

## Install
```
pip install opencv-python mediapipe numpy
```

## Controls
Number keys 1 to 4 pick the pen color (green, red, blue, yellow). Press C to clear the canvas. Press Q to quit.
